<h1>📌 About MediCare</h1>

<table>
<tr>

<td width="50%" valign="top">

<h3>🩺 What is MediCare?</h3>

<p>
<strong>MediCare</strong> is a desktop-based Doctor Consultation and
Appointment Management System developed using
<strong>Java Swing</strong> and <strong>MySQL</strong>.
</p>

<p>
The goal is simple:
</p>

<blockquote>
<strong>
Make doctor discovery and appointment management easier
through a single digital platform.
</strong>
</blockquote>

<p>
The application provides dedicated workflows for both
<strong>patients</strong> and <strong>doctors</strong>,
allowing each user type to perform the tasks relevant to them.
</p>

</td>

<td width="50%" valign="top">

<h3>⚡ What makes it interesting?</h3>

<p>
MediCare is more than a basic CRUD application.
</p>

<p>It combines:</p>

<ul>
<li>🔐 Authentication</li>
<li>👤 User management</li>
<li>👨‍⚕️ Doctor management</li>
<li>🩺 Speciality-based discovery</li>
<li>📅 Appointment scheduling</li>
<li>📊 Booking status tracking</li>
<li>📧 Email notifications</li>
<li>🔢 OTP verification</li>
<li>🖼️ Profile-picture handling</li>
<li>🗄️ MySQL database integration</li>
</ul>

</td>

</tr>
</table>

Add sensitive configuration files to:
</p>

<pre>

<h1>🚀 Getting Started</h1>

<h2>1️⃣ Clone the Repository</h2>

<pre>
git clone https://github.com/kamakashisharma49-design/Doctor-Consultation-.git
</pre>

<p>Navigate into the project:</p>

<pre>
cd Doctor-Consultation-
</pre>

<h2>2️⃣ Install Requirements</h2>

<p>Make sure the following are installed:</p>

<ul>
<li>Java JDK</li>
<li>Apache NetBeans</li>
<li>MySQL Server</li>
<li>MySQL Workbench</li>
<li>MySQL JDBC Driver</li>
<li>JavaMail dependencies</li>
</ul>

<h2>3️⃣ Create the Database</h2>

<p>
Open MySQL Workbench and create the database:
</p>

<pre>
CREATE DATABASE medicare;
</pre>

<p>
Then import the provided SQL file:
</p>

<pre>
database/medicare.sql
</pre>

<h2>4️⃣ Configure Database Connection</h2>

<p>
Update the database connection inside:
</p>

<pre>
DBLoader.java
</pre>

<p>Example:</p>

<pre>
String url = "jdbc:mysql://localhost:3306/medicare";
String username = "root";
String password = "your_mysql_password";
</pre>

<p>
Replace <strong>your_mysql_password</strong> with your MySQL password.
</p>

<h2>5️⃣ Configure Email</h2>

<p>
Configure the email account used by the application for sending
OTPs and appointment notifications.
</p>

<p>
Use an <strong>App Password</strong> instead of your normal Gmail password.
</p>

<h2>6️⃣ Open in NetBeans</h2>

<p>Open:</p>

<pre>
NetBeans → File → Open Project
</pre>

<p>Select:</p>

<pre>
Doctor-Consultation-
</pre>

<p>
Build the project and run the main login/welcome screen.
</p>

<h1>🔐 Security Considerations</h1>

<p>
MediCare includes several security-related mechanisms:
</p>

<ul>
<li>🔐 User authentication</li>
<li>🔢 OTP-based password recovery</li>
<li>📧 Email verification</li>
<li>🔒 Password change functionality</li>
<li>🗄️ Database-backed authentication</li>
<li>👤 Separate patient and doctor workflows</li>
</ul>

<h3>Recommended Improvements</h3>

<p>
For a production-ready system, additional security measures should be implemented:
</p>

<ul>
<li>Password hashing using BCrypt or Argon2</li>
<li>Prepared statements for all database queries</li>
<li>OTP expiration</li>
<li>Login attempt limiting</li>
<li>Session management</li>
<li>Environment-based secrets</li>
<li>Input validation</li>
<li>Role-based authorization</li>
</ul>
