<h2>📌 About</h2>

<table width="100%" cellpadding="12" cellspacing="0">

<tr>

<td width="50%" valign="top">

<h3>🩺 What is MediCare?</h3>

<p>
<strong>MediCare</strong> is a desktop-based
<strong>Doctor Consultation & Appointment Management System</strong>
developed using <strong>Java Swing, JDBC and MySQL</strong>.
</p>

<p>
The application provides a centralized platform where patients
can discover doctors, book appointments and track their bookings,
while doctors can manage profiles and respond to appointment requests.
</p>

</td>

<td width="50%" valign="top">

<h3>⚡ Core Capabilities</h3>

<ul>
<li>🔐 Authentication</li>
<li>👤 User management</li>
<li>👨‍⚕️ Doctor management</li>
<li>🩺 Speciality-based discovery</li>
<li>📅 Appointment scheduling</li>
<li>📊 Booking status tracking</li>
<li>📧 Email notifications</li>
<li>🔢 OTP verification</li>
<li>🖼️ Profile-picture handling</li>
<li>🗄️ MySQL integration</li>
</ul>

</td>

</tr>

<h2>🚀 Setup</h2>

<h3>1️⃣ Clone Repository</h3>

<pre>
git clone https://github.com/kamakashisharma49-design/Doctor-Consultation-.git
cd Doctor-Consultation-
</pre>

<h3>2️⃣ Requirements</h3>

<ul>

<li>Java JDK</li>
<li>Apache NetBeans</li>
<li>MySQL Server</li>
<li>MySQL Workbench</li>
<li>MySQL JDBC Driver</li>
<li>JavaMail dependencies</li>

</ul>

<h3>3️⃣ Create Database</h3>

<pre>
CREATE DATABASE medicare;
</pre>

<p>
Import the provided SQL file:
</p>

<pre>
database/medicare.sql
</pre>

<h3>4️⃣ Configure Database</h3>

<p>
Update <code>DBLoader.java</code>:
</p>

<pre>
String url = "jdbc:mysql://localhost:3306/medicare";
String username = "root";
String password = "your_mysql_password";
</pre>

<h3>5️⃣ Configure Email</h3>

<p>
Use a Gmail <strong>App Password</strong> instead of your normal password.
</p>

<pre>
EMAIL_USERNAME=your-email@gmail.com
EMAIL_APP_PASSWORD=your-app-password
</pre>

<p>
<strong>⚠️ Never commit passwords, API keys or other secrets to GitHub.</strong>
</p>

<h3>6️⃣ Run the Application</h3>

<pre>
NetBeans → File → Open Project
</pre>

<p>
Open the project, build it and run the welcome/login screen.
</p>
